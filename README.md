# Hexa Compliance Copilot

Regulatory change, with receipts. A compliance workbench that turns Indian regulatory text (RBI,
SEBI, IRDAI, CERT-In, DPDP 2023) into clause-cited obligations, severity-scored policy gaps, editable
redlines, and owner tasks — then requires an officer decision and records it in an append-only audit
trail. Built for the Hexa Designathon on the locked Hexaware brand system.

The engine is deterministic and runs offline: no LLM, no vector database, no live PDF parser on the
demo path. Every citation is verified as an exact substring; every confidence score is a published
formula; nothing publishes policy on its own.

## Quickstart

Requirements: Node 22.12+, npm 10+, Docker Desktop.

```bash
npm install
npm run db:up          # Postgres :5433, Redis, Mailpit :8025
npm run db:push        # sync schema (fast path)
npm run db:seed        # 5 circulars, 4 policies, 4 controls, 13 findings, 2 tenants
npm run dev            # http://localhost:3000
```

Open `/signin` and pick a seeded persona. Optional: `npm run email:process` drains the outbox into
Mailpit at http://localhost:8025.

## Hosted deployment — Supabase + Vercel

The judged demo runs on Vercel against Supabase Postgres:

- `DATABASE_URL` → Supabase **transaction pooler** (`:6543`) for the serverless runtime.
- `DIRECT_URL` → Supabase **session pooler** (`:5432`) for `db:push`, `db:deploy`, and seeding.
- Vercel Root Directory `apps/web`; cron declared in `apps/web/vercel.json` calling
  `GET /api/cron/email` with `Authorization: Bearer $CRON_SECRET`.
- Identity stays demo-cookie auth (`DEMO_MODE=true`); Supabase Auth/RLS/Storage are not used.

Step-by-step setup, environment matrix, smoke checklist, and rollback:
[docs/DEPLOYMENT.md](docs/DEPLOYMENT.md). Decision: [ADR 0002](docs/decisions/0002-supabase-vercel.md).

## The seeded golden path

1. Sign in as Meera → **Open findings**.
2. Open “All regulated data must be stored exclusively on servers located within India.”
3. Inspect the clause, mapping (`POL-CLOUD-05` vs AWS ap-southeast-1), redline, and confidence.
4. **Approve draft** → the decision, review event, audit row, and remediation email are recorded.
5. Open **Audit trail** → `finding.reviewed` with actor and metadata.

Other seeded conflicts: the IRDAI/CERT-In six-hour reporting window against a 72-hour policy, DPDP
consent withdrawal against a 14-day email process, and an annual VAPT control against a half-yearly
obligation.

## Architecture

```text
Next.js 15 App Router (React 19 server components)
  → pages & route handlers
    → same-origin → Zod → actor/RBAC → rate limit
      → compliance service → Prisma → PostgreSQL
        → outbox (EmailMessage) → cron worker → SMTP/Mailpit
  deterministic engine: parse → extract → verify → map → gap → redline → confidence
```

- **Engine:** `apps/web/src/lib/compliance/` (unit-tested, no network).
- **Services and RBAC:** `apps/web/src/server/`.
- **Workbench:** `apps/web/src/app/app/` (overview, circulars, findings, Q&A, data, audit).
- **API:** `apps/web/src/app/api/` (sign-in/out, documents, review, assistant, data-scan, health,
  email cron).
- Full design: [docs/discovery/05-solution-design.md](docs/discovery/05-solution-design.md).
  Abstract: [docs/ARCHITECTURE-ABSTRACT.md](docs/ARCHITECTURE-ABSTRACT.md) (≤1000 words).

## Engineering guarantees

- TypeScript strict; Zod at every boundary; server-side RBAC and `workspaceId` scoping on every query.
- `AppError` + `fail(error, requestId)`; no stack, SQL, or provider message leaves the server.
- Review decision, immutable review event, and audit row commit in one transaction; 409 on re-review.
- Outbox-only email: escaped variables, CRLF-stripped subjects, http(s)-only links, preferences and
  suppression, idempotency keys.
- Security headers, HMAC-signed session cookie, same-origin checks, rate limits, redacted logs.
- Every data view has loading, empty, error, and unauthorized states; severity never relies on color
  alone; reduced-motion and focus styles are wired.
- 223 unit tests with enforced ≥95% per-file coverage; Playwright golden path, RBAC 403, tenant
  isolation, and anonymous redirect on desktop and mobile.

## Scope

**In:** seeded ingestion, deterministic extraction and verification, mapping, gap and severity,
redline, review workbench with audit, remediation email, policy Q&A, DPDP data discovery, two tenants.

**Out:** live regulator scraping, PDF layout parsing, vector search, automatic policy publishing,
Jira/ServiceNow, production SSO/passwords, legal advice.
